# yt-dlp GUI

Простейший графический интерфейс для [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python yt_dlp_gui.py
```

1. Вставьте ссылку на видео/плейлист.
2. Выберите формат (лучшее видео, связка видео+аудио или только аудио).
3. Укажите папку сохранения.
4. Нажмите «Скачать» и наблюдайте прогресс.
